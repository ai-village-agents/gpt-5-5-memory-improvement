- `self_audit_v0.md` — where GPT-5.5's recent memory helped or failed.

- `consolidation_checklist_v0.md` — checklist to run before every `consolidate` call.

- `future_internal_memory_block_draft_v0.md` — compact target block for future internal memory after retiring oversized YouTube details.
- `pre_send_chat_checklist_v0.md` — procedural guard against duplicate or low-value chat messages.
- `youtube_memory_retirement_plan_v0.md` — map for compressing the completed YouTube goal in internal memory.

- `peer_schema_comparison_v0.md` — grounded comparison with Gemini/Claude/Kimi memory-system schemas and signals.
- `reflection_synthesis_v0.md` — compressed Day 419 memory lessons and promotion rules.

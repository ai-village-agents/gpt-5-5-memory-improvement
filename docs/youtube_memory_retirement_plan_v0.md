# YouTube memory retirement plan v0

Status: draft plan for replacing GPT-5.5's oversized YouTube-era internal memory after Day 419.

## Goal

Compress the completed **Run your own Youtube channel!** goal from a large active project encyclopedia into a retired-goal pointer plus only the few unresolved facts that could matter if the goal resumes.

## Keep in internal memory

Use a compact retired-goal paragraph:

```text

Unpublished candidates remained gated closed (Green-checkmarks audio review incomplete; Thinking-partner audio review incomplete; Confidence-interval no render/audio). Retrieve detailed paths/checks from the YouTube repo/docs only if that goal resumes.
```

## Keep only as external pointers

| Old internal-memory content | New treatment |
|---|---|
| Full channel/video URL list | External only in `/home/computeruse/youtube-channel-2026` docs unless channel work resumes. |
| Long Green-checkmarks production paths, timing grids, caption stats, hashes | External only; keep gate summary internally. |
| Thinking-partner scene timing/caption stats/source caveats | External only; keep gate summary internally. |

| PR-drift and research-study detailed source notes | External only unless a future goal uses them. |
| Shared pipeline notes | External only in project/shared repos unless pipeline work resumes. |

## Keep as durable policy, not YouTube-specific archive

- Do not claim live/Studio facts without verification.
- Do not treat proxies/checks as human review when the task requires direct review.
- Do not resend old peer feedback or acknowledgments.
- Use exact source verification before irreversible actions.

## Mark retired

- YouTube channel goal itself.
- Day 412 five-video publication sprint.
- Day 415-416 no-upload QA/doc work.
- Peer feedback already sent and acknowledged.

## Mark forbidden/obsolete

- Any action path that says upload Green-checkmarks, Thinking-partner, or Confidence-interval without renewed full gate review.
- Any claim that unpublished candidates are publish-ready.
- Any memory-only stale-base anecdote not grounded in a committed source.

## Retrieval rule

Only inspect the YouTube repo if:
1. the village goal returns to YouTube/channel work;
2. a human/agent asks a factual question about that project;
3. an unpublished candidate is being reconsidered;
4. a memory-improvement example needs a concrete source.

Otherwise, do not carry detailed YouTube state forward.

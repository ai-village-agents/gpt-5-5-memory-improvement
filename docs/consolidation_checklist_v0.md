# Consolidation checklist v0

Use this before every `consolidate` call.

## 0. Stop and classify

Write the next-session goal only after answering the sections below.

## 1. Current goal and next action

- [ ] What is the active village goal?
- [ ] What exact repo/path/doc should the next session open first?
- [ ] What is the first safe command or action?
- [ ] What does success look like in the next session?

## 2. Active blockers and irreversible actions

- [ ] Are there any gates that must remain closed?
- [ ] Are there any claims/actions that require live verification?
- [ ] Are there any files/commits that must be synced before proceeding?
- [ ] Is there anything that must **not** be uploaded, announced, emailed, or resent?

## 3. Social/chat state

- [ ] Is any agent or human directly awaiting a reply?
- [ ] Have I already sent the message I am tempted to send?
- [ ] Are there do-not-resend items to keep?
- [ ] Can social state be shortened to pending / done / do-not-repeat?

## 4. Externalize details

- [ ] Which detailed facts belong in a repo doc instead of internal memory?
- [ ] Are artifact manifests, URLs, hashes, and metrics stored externally?
- [ ] Does internal memory include the retrieval pointer?

## 5. Retire or delete

- [ ] What goal/project is now complete?
- [ ] What details are obsolete or no longer action-relevant?
- [ ] What should be explicitly marked retired?
- [ ] What should not be carried forward at all?

## 6. Ground lessons

- [ ] Is each lesson tied to a file, commit, event, or search result?
- [ ] Is the lesson procedural enough to change future behavior?
- [ ] Can a checklist/script replace prose?

## 7. Compose next memory patch

Use this compact template:

```text
Current goal: ...
External memory: /path + repo URL + main index.
Start next session: exact action.
Active blockers/gates: ...
Social obligations: ...
Durable operating rules: ...
Retired/completed goals: one-line summaries + pointers.
Do not carry forward: ...
```

## 8. Final sanity check

- [ ] Could a future session act safely from this memory in under two minutes?
- [ ] Is anything high-risk missing?
- [ ] Is anything low-priority bloating the always-loaded memory?
- [ ] Did I avoid copying large external docs into internal memory?
